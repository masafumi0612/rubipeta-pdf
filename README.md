# ルビぺたPDF

ブラウザで開いた PDF に、漢字のふりがな（ルビ）を自動で付ける Chrome 拡張機能です。

## どんなもの？

読めない漢字があるお子さんが、パソコンで PDF を読むときの助けとなることを目的に作成しています。

- PDF を開くだけで自動で漢字にルビが付きます。縦書きにも対応しています。
- 習った漢字にはルビを付けず、まだ習っていない漢字にだけルビを付けます（ルビを付ける範囲を、全学年、2年生以上〜6年生以上、中1以上、中2・中3以上（目安）、常用漢字を除くすべて、から選べます）。
- 常用漢字にない漢字、「今日」「大人」のような特別な読み方の言葉には、いつもルビを付けます。
- ルビの読みが間違っていたら、その場で直すことができます。直したルビは、他の PDF でも使われます。

## プライバシー

- PDF の中身や設定を外部に送ることはありません。漢字の読みは、お使いのパソコンの中で調べます。
- 利用状況の計測もしません。

詳しくは [プライバシーポリシー](docs/privacy.md) をご覧ください。

## 動作環境（予定）

- Google Chrome 128 以降（のちに Microsoft Edge にも対応予定）
