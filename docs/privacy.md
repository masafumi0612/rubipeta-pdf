# ルビぺたPDF プライバシーポリシー

ルビぺたPDF は、ブラウザで開いた PDF の漢字にふりがな（ルビ）を付ける Chrome 拡張機能です。このページでは、拡張機能が扱う情報と、その置き場所を説明します。

## まとめ

- 開いた PDF の中身・URL・設定・直したルビを、開発者や外部のサーバーに送りません。
- 漢字の読みは、拡張機能に入っている辞書を使って、お使いのパソコンの中で調べます。
- 名前・メールアドレスなど、個人情報は集めません（問い合わせのフォームに、お返事のためのメールアドレスを書いてもらったときを除きます）。
- 利用状況の計測・広告はありません。
- Chrome ウェブストアのユーザーデータに関するポリシー（[User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies)。限定的な使用の要件を含む）に従います。拡張機能が扱う情報は、PDF にルビを付けて表示するためだけに使い、他の目的に使ったり、人に渡したり、売ったりしません。

## 扱う情報と置き場所

| 情報                                                    | 何に使うか                           | 置き場所                                                                                |
| ------------------------------------------------------- | ------------------------------------ | --------------------------------------------------------------------------------------- |
| 開いた PDF（ウェブの PDF・パソコンに保存した PDF）      | 画面に出し、ルビを付けるため         | 保存しません。開いている間だけ使います                                                  |
| 漢字の読みを調べた結果                                  | 同じ文を何度も調べないため           | PDF を開いている間だけ、メモリに保持します。PDF を閉じると消えます                      |
| 設定（ルビの量・見た目・自動で開くスイッチなど）        | 次に開いたときも同じ設定にするため   | Chrome の同期用の保存先（下の「Chrome の同期」）                                        |
| 直したルビ（言葉と読み方）                              | 他の PDF でも同じ読み方にするため    | Chrome の同期用の保存先。多くなって入りきらないときは、このパソコンの中だけに保存します |
| 初めて入れたときの案内を閉じたかどうか                  | 案内を何度も出さないため             | このパソコンの中だけに保存します                                                        |
| 直近のエラー（20 件まで。時刻・起きた場所・エラーの文） | 不具合を知らせてもらうときに使うため | このパソコンの中だけに保存します。エラーの文に URL が入っていても、残す前に消します     |

作ったルビ付きの PDF は、［保存］を押したときだけ、Chrome のダウンロードのフォルダに入ります。［開く］で新しいタブに出したルビ付きの PDF は、少しのあいだだけ拡張機能の中に残ります。次の PDF を作ったとき、別の PDF を開いたとき、または1日たつと、自動で消えます。

### Chrome の同期

設定と直したルビは、Chrome の同期用の保存先（`chrome.storage.sync`）に入れます。Chrome の同期をオンにしていると、Chrome が同じ Google アカウントでログインした他の Chrome にも同じ内容を届けます（同期は Chrome の機能です。ルビぺたPDF が自分で送るものではありません）。

同期で届くのは、設定と直したルビだけです。開いた PDF の中身や URL は入りません。ただし、直したルビに人の名前などを登録すると、その言葉と読み方も同期されます。

## 通信するもの

ルビぺたPDF が通信するのは、サイトから開きたい PDF を読み込むときだけです。

- 「PDF を開いたら、自動でルビを付ける」で開くときは、Chrome が読み込みかけた PDF を、同じ URL からもう一度読み込みます。ログインが必要なサイトでも開けるよう、そのサイトのログインの情報（Cookie）をそのサイトにだけ付けます。
- URL を貼って開くときは、その URL から PDF を読み込みます。
- 辞書・フォント・PDF を読むためのデータは拡張機能に入っているので、外から読み込みません。

設定の画面の「報告用の情報をコピー」は、拡張機能と Chrome の版、直近のエラーをクリップボードにコピーするだけです。PDF の URL や中身は入りません。

## 権限とその理由

| 権限                                           | 理由                                                                                                                                                                                         |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `offscreen`                                    | 漢字の辞書を、画面に出ない拡張機能のページの中で一度だけ読み込むため                                                                                                                         |
| `declarativeNetRequestWithHostAccess`          | 許可されたサイトの PDF を、ルビぺたPDF のリーダーで開き直すため                                                                                                                              |
| `storage`                                      | 設定、直したルビ、入れた直後の案内を閉じたかどうか、直近のエラーを保存するため                                                                                                               |
| 「すべてのサイト」へのアクセス（あとから許可） | 設定の画面の「PDF を開いたら、自動でルビを付ける」をオンにしたときだけ求めます。PDF を見分けて、リーダーで開き直すためだけに使います。ページの中身を読み取ったり送ったりすることはありません |
| 1つのサイトへのアクセス（あとから許可）        | 設定の画面に URL を貼って開くとき、そのサイトの PDF を読み込むために求めます                                                                                                                 |
| ファイルの URL へのアクセス（Chrome の設定）   | パソコンに保存した PDF を開いたときも自動でルビを付けたいときだけ使用する設定です。Chrome の画面でオンにすることができます                                                                   |

## 情報の消し方

- 拡張機能を Chrome から取り除くと、このパソコンに保存したものは消えます。
- 直したルビは、設定の画面の一覧から1つずつ消せます。設定は「設定を最初の状態にもどす」で最初に戻せます。
- 同期したものは、Chrome の設定の「同期と Google サービス」で拡張機能の同期をオフにすると、他の Chrome に届かなくなります。Google アカウントに残った同期のデータは、Chrome の同期のデータを消す手順で消せます。
