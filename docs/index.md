# ルビぺたPDF

ルビぺたPDF は、ブラウザで開いた PDF の漢字にふりがな（ルビ）を自動で付ける Chrome 拡張機能です。読めない漢字があるお子さんが、パソコンで PDF を読むときの助けとなることを目的に作成しています。漢字の読みはお使いのパソコンの中で調べ、PDF の中身を外部に送ることはありません。詳しくは[プライバシーポリシー](privacy)をご覧ください。

## 見本の PDF

試すための見本の PDF です（文はすべて、この拡張のために書き下ろしたものです）。拡張を入れて「PDF を開いたら、自動でルビを付ける」をオンにしてから開くと、ルビ付きで開きます。
